文字がない・不完全

原音を再生できるか確認し、マイク・音声認識の許可、選択言語、処理状況を確認してください。再試行前に原音を残してください。

AI の設定と料金

Apple の端末内機能は端末と言語により異なります。外部の文字 AI は任意で、ご自身の設定と API キーが必要です。サービス料金はアプリ購入とは別です。

Watch の同期

iPhone で受信と再生を確認するまで Watch の原音を残し、接続と同期状態を確認してください。

タスクとカレンダー

実行前に内容、日時、担当者、出典を確認してください。明示的な操作でシステム予定を作成・更新します。Saynary で非表示にしてもシステム予定は削除されません。

バックアップと削除

重要なデータの削除や復元前に、設定から完全なバックアップを書き出してください。書き出したファイルや共有済みコピーは別に管理します。

お問い合わせ

アプリのバージョン・ビルド、端末、OS、再現手順、発生時刻をメールでお知らせください。パスワードや API キーは送らないでください。録音や健康情報は、ご自身が共有を選んだ場合に限り添付してください。
