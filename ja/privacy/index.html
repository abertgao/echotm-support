プライバシーポリシー

施行日：2026年11月25日 · Saynary 0.3.5

端末内の記録

録音、文字起こし、要約、タスク、日時、設定は端末に保存されます。Watch と iPhone は Apple の端末間通信で記録を交換します。端末内での録音にアカウントは不要です。Saynary 自社のサーバーに録音を保存することはありません。

許可と任意の情報

マイクはユーザーが開始する録音に使用します。標準の音声認識は端末内処理を使用します。対応状況は端末と言語によって異なります。任意のカレンダー許可で予定を表示し、明示操作で予定を変更します。非表示はシステム予定の削除ではありません。任意のヘルスケア許可で心拍、心拍変動、睡眠、ワークアウトを読み取り、端末内の参考情報に用います。健康データの書き込みや医療診断は行いません。位置情報を有効にすると、地名の取得のため座標が Apple の地理サービスに送られる場合があります。

任意のモデルとネットワーク

対応端末では Apple の端末内モデルを利用できます。音声認識や話者識別のローカルモデルをダウンロードすると、配信元が IP アドレスなどの通信情報を受け取る場合があります。モデルのダウンロード時に録音は送信されません。外部のテキスト AI を有効にすると、関連する文字起こし、記録の文章、質問、会話履歴が、選択した提供元に送られる場合があります。文字起こしの修正時は個人辞書の語句が含まれる場合があります。テキスト AI へのリクエストには、原音、Apple のヘルスケアの測定値とそれに基づくラベル、自動で付けた場所のラベルは含まれません。声紋と話者プロファイルは端末に保存されます。記録の文章に含まれる名前は、その文章とともに送信される場合があります。API キーは端末のキーチェーンに保存し、認証に必要なときに設定済みの提供元へ送信します。処理地域と保存期間は提供元によって異なります。設定で外部 AI を無効にするか、キーを削除できます。

Qwen による文字起こし（任意）

Qwen の接続テストでは、公開サンプルの URL と、認証に必要な Alibaba Cloud の API キーを送信します。個別の録音に Qwen を使うことを承認するか、今後の対象録音の既定の方法として別途承認すると、Saynary は変換した音声を選択した地域（中国・北京、またはシンガポール）の Alibaba Cloud Model Studio に直接送信します。サービスからは文字起こし、タイムスタンプ、「話者 1」などのラベルが返ります。設定で端末内の方式に切り替えるか Qwen のキーを削除すると、その後の自動送信を停止できます。入出力の標準保存期間は最長 30 日で、例外や対象ワークスペースの設定については、Alibaba Cloud のデータ保存ポリシーをご覧ください。端末上で録音を削除しても、既に提供元へ送られたコピーは削除されません。

共有、保管、削除

書き出し、バックアップ、共有、ワークフロー連携では、選択した保存先やサービスに情報が渡ります。クラウド保存にはそのサービスの規約が適用されます。アプリ内の記録・原音と、書き出したコピーは別に管理してください。端末内の削除は、共有済み・送信済みのコピーを自動削除しません。アンインストールでアプリ領域のデータが失われる場合があります。キーチェーンや書き出したファイルには別の保存期間があります。

広告と追跡

現在のアプリには広告・広告追跡 SDK を組み込んでいません。任意の外部サービスでは上記の情報処理が行われる場合があります。
