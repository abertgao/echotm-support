隐私政策

生效日期 / Effective: 2026-11-08 · 适用版本 / App version: 0.3.5

适用于 Echotm（应用内名称 Echo / 回声）。

本地记录

应用在设备上保存录音、转写、整理结果、总结、待办、时间及用户设置。原始录音默认保留本地；配对手表与手机使用苹果设备间同步能力交换记录。应用没有 Echo 自有业务账户或业务云服务器。本地录音无需注册 Echo 账户。

可选权限与上下文

麦克风用于用户主动发起的录音；语音识别请求被设置为设备端识别，实际能力受系统及语言可用性影响。

启用日历权限后可读取日程用于展示，并在明确操作后创建或更新关联任务日程。仅从应用隐藏日历展示不会删除系统日程。

启用健康权限后可读取心率、心率变异性、睡眠及体能训练信息，用于本地个人状态上下文。当前代码不写入健康库。状态估计和标签不是医疗诊断。

启用地点功能后可记录位置与时间，并通过苹果系统地理编码服务把坐标转换为地点名称；因此相关位置可能由系统发送给苹果处理。这不是“所有数据从不离开设备”的产品。

可选模型与网络

兼容设备上可使用苹果端侧模型。只有配置并启用外部文字 AI 服务后，应用才使用相应提供商的服务。请求可包括与功能相关的记录文字、对话以及身体状态或地点名称等上下文标签；第三方同时会收到网络请求相关信息。原始音频不会作为文字模型请求上传。

部分本地语音或说话人模型需联网下载；下载服务可能收到 IP 地址等网络信息，下载模型不等于上传录音。

用户的 API Key 用于向其配置的服务认证，并由设备钥匙串保存。提供商对请求的保留、处理地区与用途取决于该提供商政策，本政策不能替第三方承诺不保存或不用于训练。用户应按所使用服务的条款配置和使用。

用户主动导出、分享、备份、恢复或连接工作流时，内容会进入用户选择的文件位置、应用或工作流设备；若选择云盘，其处理受相应服务条款约束。

保留与删除

记录按应用中配置的保留和删除设置处理。可以在应用内删除记录和相关音频，或管理导出的文件/备份。删除本地内容不会自动删除已经导出、分享或发送给外部服务的副本。

卸载应用可能移除应用容器内的数据，系统钥匙串及用户自行导出的文件有独立生命周期。请通过应用中的配置管理和文件管理功能分别处理。

广告与追踪

当前代码未接入广告或广告追踪 SDK，隐私清单声明不进行追踪。不能据此省略可选外部服务涉及的数据处理披露。
